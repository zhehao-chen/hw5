Since 16 October one partner integration has received 9,400 responses of
`401 authentication required`. Its HTTP library sends
`Authorization: bearer <token>` with the scheme in lower case, and the same
tokens work when the scheme is written `Bearer`. HTTP treats the scheme name as
case-insensitive, so the tokens themselves are fine.
