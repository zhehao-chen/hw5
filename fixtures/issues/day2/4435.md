The weekly docs check compares the status codes in each handler with the API
reference. `POST /uploads` returns 413 when the file is over the size limit and
415 when it is not a `.csv`, each with a translated `error` message, but
`docs/API.md` documents only the 202 response and the 422 content errors. Two
integration partners asked about 415 this month.
