Staging runs with `UPLOAD_MAX_BYTES=262144` (256 KB) to keep test files small.
Every upload over that size gets 413 with
`The file is larger than the 0 MB limit`, and French users see `0 Mo`. The limit
itself works; only the number in the message is wrong, because it is rounded to
whole megabytes and anything under 512 KB comes out as zero.
