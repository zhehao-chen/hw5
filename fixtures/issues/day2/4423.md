The mobile client sends `Accept-Language: en;q=0.3, fr-FR;q=0.9`. Over the past
week 2,140 upload error responses to it came back in English, although French
has the higher weight in that header. The API takes the first supported language
in the list and ignores the `q` weights. Browsers usually list languages in
order of preference, which is probably why the web client hasn't run into this.
