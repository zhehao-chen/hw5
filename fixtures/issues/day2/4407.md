Since 20 October the API has answered 143 upload requests with 500
`internal error`, logged as `unhandled error` with
`MulterError: Unexpected field`. They all come from one integration that sends
the file in a form field named `statement` instead of `file`. A misnamed field
is the client's mistake and should get a 400 that says which field is expected,
the way an oversized file already gets its own clear message.
