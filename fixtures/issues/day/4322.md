I set the poll interval in our YAML defaults file as
`QUEUE_POLL_INTERVAL_MS: 500`, the name used in the configuration reference, and
it was silently ignored. Reading the shipped `config/app.yaml`, the file uses
nested camelCase keys instead (`queue:` and then `pollIntervalMs:`). The
reference says each value can come from the YAML file but never shows what the
key is called there. A column with the YAML key next to each variable would have
saved me an afternoon.
