The weekly docs check compares each documented response with what the handler
returns. For `GET /uploads/:id`, `docs/API.md` lists `status`, the `inserted`
and `duplicates` counts, `error` and `row`, but the response also carries `id`,
`filename`, `createdAt` and `finishedAt`. One customer's client already reads
`finishedAt`, so these are worth documenting.
