The weekly security scan imported a test statement with the description
`=HYPERLINK("https://example.invalid","Refund")` and exported the report as CSV.
The cell came out exactly as written, so Excel and Google Sheets treat it as a
formula when the file is opened. Text values that start with `=`, `+`, `-` or
`@` should be neutralised in CSV exports. The XLSX export stores the same value
as plain text and is not affected.
