Since the staging deploy at 14:02 UTC on 22 October, every upload has failed
with `Error: Region is missing`. The new compose file passes `S3_REGION` through
from the host, where it is unset, so the container sees an empty string.
`config/app.yaml` still sets `eu-west-1`, but the empty variable wins over it.
Numeric settings that are empty fall back to their defaults, so string settings
behave differently.
