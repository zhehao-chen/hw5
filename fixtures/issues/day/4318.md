Over the past week the API answered 389 uploads with 415
`Only .csv files can be uploaded`. In every case the file name ended in `.csv`
but the file part's content type was `application/octet-stream`. Most come from
two customers' scripts that upload with `curl -F file=@statement.csv`, which
sends that type for extensions it doesn't know. The same files upload fine
through the web form.
